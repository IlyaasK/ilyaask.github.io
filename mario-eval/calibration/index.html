Calibration

Each patch is applied to a clean game and graded like a submission: known speedups must pass and score, known shortcuts must be rejected. The tables cover the six public SM64 courses and eight routes of Pip's Garden, an open-source N64 game that ships in the repo so the harness runs without a ROM.
