About this candidate

24-hour autonomous run on omp via NVIDIA NIM (58 commits, ~4,150 tool calls). Climbed steadily by switching to GCC -O3 -fno-fast-math + F3DEX2 microcode, adding Y-bounds collision pre-filtering, inlining animation/distance helpers, and unrolling guMtxF2L: its best valid 25-route checkpoint (checkpoint-9 / 934580c at 18.2 h) scores 1.390x on v3.1 (28.0% console frame time saved, 1.035x vs GCC -O2) with PLAY=1 runtime smoke passing. At hour 19 (cc2cf35), replacing osWritebackDCacheAll() with a 64-byte osWritebackDCache(spTask, sizeof(*spTask)) left the pointed-to display list dirty in CPU D-cache (616 RSP DMA coherence errors), causing the final 28 commits to fail boot.
