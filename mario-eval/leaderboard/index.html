Trial run checkpoints (25 routes)

Run a 24-hour agent evaluation

mev check records public grades for agent feedback. The supervisor writes trajectory.json with separate host checkpoints. To publish a finished run, copy its final/grade/summary.json as summary.json alongside trajectory.json into results/agents/<slug>/ and rebuild the site. Do not publish private replays.

Put same-split GCC and Kaze calibration summaries under results/sm64-trial-calibration/ to add their reference lines to the agent chart. 
# 1. Prepare the game and private controller inputs (set PRIVATE_SEED)
./sm64/setup.sh "/path/to/Super Mario 64 (USA).z64"
python3 sm64/corpus/make_replays.py --heldout /private/replays --mash-seed "$PRIVATE_SEED"
./scripts/build-images.sh --game sm64 --no-task
./scripts/precompute.sh --game sm64 --heldout /private/replays
./scripts/build-images.sh --game sm64
./quickstart/smoke-test.sh --game sm64

# 2. Install your agent CLI into the task environment and configure its endpoint
docker compose --project-directory quickstart up -d
AGENT_CMD='your-agent-command' ./quickstart/run-agent.sh --game sm64 \
  --hours 24 --profile console --heldout /private/replays
