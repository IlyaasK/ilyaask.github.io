Leaderboard & Reference Ceiling

Every submission is graded on 12 Super Mario 64 courses (6 public + 6 private held-out, 240 frames each) on an instrumented ares N64 console model (93.75 MHz VR4300 + 16 KB I$ / 8 KB D$, 62.5 MHz RSP & RDP, 4 MB RDRAM). To calibrate how much headroom exists above a naive -O2 recompile, we engineered a 3-rung Kaze Emanuar Reference Ceiling under the exact same gates and toolchain given to 24-hour agents.

Run a 24-hour agent evaluation

Agent runs record every inner-loop mev profile milestone to /task/.mev-history.jsonl and emit results/<run>/trajectory.json automatically when graded. Copy any finished run directory into results/agents/<slug>/ and rebuild the site to plot its 24-hour scaling curve above.

# 1. Supply your legally dumped US Super Mario 64 .z64 ROM (never committed or shipped)
./sm64/setup.sh "/path/to/Super Mario 64 (USA).z64"
./scripts/build-images.sh --game sm64
./scripts/precompute.sh --game sm64

# 2. Verify container isolation, build, profiler, and grader end-to-end
./quickstart/smoke-test.sh --game sm64

# 3. Launch a 24h isolated agent run + held-out grading + trajectory extraction
./quickstart/run-agent.sh --game sm64 claude
