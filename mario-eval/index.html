Make a Nintendo 64 game cheaper to run. Don't change it.

Mario Eval is a 24-hour reinforcement-learning-with-verifiable-rewards environment modelled on GBA Eval. An agent gets the C decompilation of Super Mario 64 (or the open-source Pip's Garden game), pinned N64 compilers, an instrumented cycle/cache/RDP-accurate ares emulator and a profiler, and must speed up real 4 MB console execution while keeping gameplay, picture, and 40 dB audio faithful.

v2.0 Ready: 12-course Super Mario 64 suite + 8-route Pip's Garden suite, headline console frame-time profile (max(CPU, RSP, RDP)), Player Equivalence + Hyrum's Law gates, 24-hour trajectory telemetry, and verified Kaze Emanuar Reference Ceiling rungs.

How a submission is graded

console headline

Per-frame max(CPU_ms, RSP_ms, RDP_ms) within 4 MB RDRAM — true N64 frame rate.

speed diagnostic

93.75 MHz VR4300 CPU time per frame (COUNT ticks), including 16 KB I$ / 8 KB D$ stalls.

rdp diagnostic

62.5 MHz RDP combiner, Z/blend RMW, TMEM upload & pipe-sync cycles.

rsp diagnostic

62.5 MHz RSP Fast3D + ABI1 audio microcode busy cycles per frame.

traffic diagnostic

RDRAM bytes moved per frame across CPU caches, SP, DP, PI & SI DMA.

memory diagnostic

Distinct 16-byte RDRAM lines touched after boot (hard 4,194,304 B ceiling).
