How a submission is graded

console headline

Per-frame max(CPU_ms, RSP_ms, RDP_ms, RDRAM_ms) within 4 MB RDRAM — true console frame time.

speed diagnostic

93.75 MHz VR4300 CPU cycles per frame, including 16 KB I$ / 8 KB D$ stalls and RCP bus contention.

rdp diagnostic

62.5 MHz RDP combiner, early-Z rejection, 4-bank 2 KB RDRAM row misses, TMEM loads & syncs.

rsp diagnostic

62.5 MHz RSP Fast3D graphics & ABI1 audio microcode busy cycles per frame.

traffic diagnostic

RDRAM bytes moved per frame across CPU caches, SP, DP, PI, SI & 60 Hz VI scanout.

memory diagnostic

Distinct 16-byte RDRAM lines touched after boot (hard 4,194,304 B retail ceiling).
